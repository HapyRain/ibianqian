> 每项勾选即代表通过；任一项失败 → 修复后重新验证。

- [ ] 顶部「项目」标签栏正常；窄窗（≤768px）下布局不破、可滚动
- [ ] 新建/删除项目：至少保留 1 个；重命名重名时提示「已存在同名项目」
- [ ] **项目切换方向滑入**：点右侧项目 → 面板从右滑入；点左侧项目 → 从左滑入（0.3s 一次，无跳变）；点当前项目不重播

## B. 状态与排序

- [ ] **状态变化瞬间**一次反馈：改状态时图标播一次（圆环落定/弧转半圈/对勾描边）后归于安静；本地与同事远程同步均触发；页面加载不播
- [ ] **排序默认倒序**：新增任务出现在**第一行**；改状态后出现在目标状态组**第一行**
- [ ] 排序开关：点筛选栏末尾「倒序/正序」→ 切换后所有行**平滑滑位**（无跳变）；刷新后偏好保留
- [ ] **全部视图**改状态：行滑到目标组内位置（视口内匀速、出屏弹射），无瞬移
- [ ] **筛选视图**改状态：行飞向目标 tag、缩小被吸收；约 1s 后目标筛选按钮**计数闪烁**；「全部」视图不闪

- [ ] 查看器**黑屏等图**：点开瞬间纯黑（无缩略图放大版/无模糊渐进），图片下载完成一次性放出完整图；**同一张图反复打开/翻页不闪烁**（uploads immutable 缓存秒开）；首次加载黑屏等待可接受

## E. 删除
- [ ] 长按删除按钮 ≥700ms 蓄怒（变红颤抖）→ 松手弹确认气泡 + 幕布渐亮 + 行聚光
- [ ] 拖出按钮松手 = 终止删除；点幕布/取消 = 复原
- [ ] 确认删除：多行 → 行高收起 + 下方行平滑上移（**无跳变**）；仅剩一行 → 渐隐
- [ ] 删除确认幕布**压暗全页**（含搜索条/筛选行/小火箭），只有被删行聚光、确认气泡清晰

## F. 备注
- [ ] 备注默认**只读**显示内容 + 作者色点 + 时间 + 修改/删除按钮（无上传/确认按钮）
- [ ] 点「修改」→ 编辑框**淡入展开**（无闪现、无双框共存）；含上传图片、确认、取消（取消还原内容）
- [ ] 编辑确认后：时间刷新为当前时间 + 出现「（已修改）」灰色标记
- [ ] 删除备注 → **二次确认**（确认才删）
- [ ] 他人备注只读（无修改/删除入口）；服务端归属校验（跨端验证）

## G. 数据安全

- [ ] 导出：⋮ 菜单 → 导出 JSON（浏览器下载 `任务清单备份-时间戳.json`）

- [ ] 离线补发：断开服务 → 新增/修改几条 → 重启服务 → 提示「离线期间的 N 条修改已同步」，数据不丢
