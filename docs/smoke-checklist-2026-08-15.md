# 打包前手工冒烟清单（2026-08-15 · 对齐当前 0.1.0 功能）

> 打包前必过清单。运行 `npm start`（浏览器）或 `npm run electron` 逐项确认；打包前再按「上线顺序」操作。
> 每项勾选即代表通过；任一项失败 → 修复后重新验证。

## A. 基础与布局
- [ ] **加载无偏移**：刷新页面首帧元素即在正确位置（无偏下 50px、无 0.5s 弹回、无闪烁）
- [ ] 总分卡片：搜索条（浅色底+横线）→ 筛选/新增行 → 任务行，一体成卡片
- [ ] 行内五列统一：名称 | 图片 | 状态 | 备注 | 删除，控件等高 32px、间距一致
- [ ] 顶部「项目」标签栏正常；窄窗（≤768px）下布局不破、可滚动
- [ ] 新建/删除项目：至少保留 1 个；重命名重名时提示「已存在同名项目」

## B. 状态与排序
- [ ] 状态胶囊三动效：待修复=暖灰呼吸点、修复中=科技蓝扳手拧螺栓（棘轮咔哒）、已完成=绿色电池+黄色闪电偶尔滋滋
- [ ] **排序默认倒序**：新增任务出现在**第一行**；改状态后出现在目标状态组**第一行**
- [ ] 排序开关：点筛选栏末尾「倒序/正序」→ 切换后所有行**平滑滑位**（无跳变）；刷新后偏好保留
- [ ] **全部视图**改状态：行滑到目标组内位置（视口内匀速、出屏弹射），无瞬移
- [ ] **筛选视图**改状态：行飞向目标 tag、缩小被吸收；约 1s 后目标筛选按钮**计数闪烁**；「全部」视图不闪
- [ ] 状态胶囊动效在状态切换后重新触发；下拉选项圆点颜色（灰/蓝/绿）正确

## C. 搜索
- [ ] 搜索框按任务名称实时过滤（不区分大小写）；清空恢复；与状态筛选叠加生效

## D. 多图与查看器
- [ ] 上传第 7 张被拦截（提示「最多 6 张」）；备注图片同样 6 张上限
- [ ] 牌堆最多叠 6 张可见；hover 抽卡；点第 N 张 → 从该张展开、背景变黑、落定
- [ ] 查看器 ←/→ 翻页、n/N 提示、× 或点背景关闭（缩回原位）
- [ ] 查看器右下角删除 → **居中确认框（渐隐出入场）** → 删后切下一张 / 尾张回第一张 / 删空关查看器；删除成功提示**可见**（不被黑幕挡）
- [ ] 备注 mini 牌堆点击进查看器（无删除钮）；作者可逐张 ✕ 删图

## E. 删除
- [ ] 长按删除按钮 ≥700ms 蓄怒（变红颤抖）→ 松手弹确认气泡 + 幕布渐亮 + 行聚光
- [ ] 拖出按钮松手 = 终止删除；点幕布/取消 = 复原
- [ ] 确认删除：多行 → 行高收起 + 下方行平滑上移（**无跳变**）；仅剩一行 → 渐隐
- [ ] 删除确认幕布**压暗全页**（含搜索条/筛选行/小火箭），只有被删行聚光、确认气泡清晰

## F. 备注
- [ ] 备注默认**只读**显示内容 + 作者色点 + 时间 + 修改/删除按钮（无上传/确认按钮）
- [ ] 点「修改」→ 编辑框**淡入展开**（无闪现、无双框共存）；含上传图片、确认、取消（取消还原内容）
- [ ] 编辑确认后：时间刷新为当前时间 + 出现「（已修改）」灰色标记
- [ ] 删除备注 → **二次确认**（确认才删）
- [ ] 他人备注只读（无修改/删除入口）；服务端归属校验（跨端验证）

## G. 数据安全
- [ ] 服务端备份：修改几次数据后 `D:\Bug清单\{用户}\backups\` 出现 `data-*.json`（保留 20 份轮转）
- [ ] 删除前快照：删除项目/任务/备注后 `backups\pre-delete-*.json` 生成（保留 5 份）
- [ ] 导出：⋮ 菜单 → 导出 JSON（浏览器下载 `任务清单备份-时间戳.json`）
- [ ] 导入：导入 JSON → **覆盖确认** → 成功后全量刷新；引用缺失图片时提示 N 张
- [ ] 离线补发：断开服务 → 新增/修改几条 → 重启服务 → 提示「离线期间的 N 条修改已同步」，数据不丢
