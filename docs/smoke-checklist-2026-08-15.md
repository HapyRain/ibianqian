# 体验改版手工冒烟清单（2026-08-15）

> 打包前必过清单。运行 `npm run electron`（或 pack814 的 exe）逐项确认。

## A. 视觉皮肤
- [ ] 全界面无纯白 #FFFFFF 面板；背板 #EDEBE4、面板 #F7F5EF、弹窗 #FFFDF6 米白
- [ ] 连接三态：断网=红点+文案红；重连中=琥珀闪烁；已连接=绿点呼吸

## B. 扑克牌堆
- [ ] 多图堆叠：第 1 张最上层最显眼，2/3/4 向右下垫底，右下角"n 张"徽标
- [ ] 抽卡 hover：碰到哪张哪张弹起扶正（压过邻牌），离开弹回
- [ ] 点第 3 张 → 从该张位置展开放大、**背景同步变黑**、落定精确停在第 3 张
- [ ] ←/→ 翻页（260ms 平移）、n/N 提示、× 或点背景 → 缩回原位
- [ ] Esc 关查看器；备注弹窗内点缩略图查看器浮于弹窗之上

## C. 删除全链路
- [ ] 快速点击 → 释放抖动+红圈 → 渐隐黑幕 + 行矩形柔光捧出 + 确认气泡
- [ ] 长按 ≥700ms → 按钮渐黄转红 + 颤抖升级；**拖出按钮松手 = 终止**；原地松手 = 正常流程
- [ ] 点幕布/取消 = 全部复原
- [ ] 确认删除 → 幕布渐亮 + 红光一闪 + 下面一行平滑上滑盖住（**无跳位、无回弹**）+ 文件被服务端清理
- [ ] 最后一行删除时坍塌过程内容不外露

## D. 按钮四态
- [ ] 新增（垒上）：悬停提起 → 按下落定（＋转 90°）→ 松开轻弹；新行"生长"进入
- [ ] 上传（托举发射）：悬停箭头抬 → 按下沉 → 松开箭头飞出；新牌从上方落入牌堆、计数 +1
- [ ] 备注（便签展开）：悬停翘角 → 按下贴平 → 松开弹回；面板米白展开

## E. 任务栏与备注多图
- [ ] 窄窗任务标签自动多行、无横向滚动；宽窗 ≥1200px 四栏加宽
- [ ] 拖拽排序：目标前后半区分别出现左/右竖线，松手落位正确，可拖到最末
- [ ] 备注弹窗：多选上传 → 逐张暂存预览 → 添加备注后 mini 牌堆显示；点击从第一张进查看器；作者可逐张 ✕ 删除；删备注清全部文件
- [ ] 单条 20 张上限提示；两步式上传中途断网 → 已传文件被补偿清理

## F. 回归底线
