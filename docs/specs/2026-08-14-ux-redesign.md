# 任务清单 · 前端体验改版设计（2026-08-14）

> 状态：设计定稿（经视觉伴侣逐屏确认）。本文件是后续实施计划的唯一规格来源。

## 1. 目标与原则

- **亮色主题重设计**：暖调纸面、无纯白、克制配色，"简约而不简单，处处是设计，用着舒服"；暗色主题留待后期。
- **连贯动效**：所有交互"从触点出发、反向回原点"，全程 150-340ms，同族缓动，无跳变无闪黑。
- **响应式**：小窗体紧凑、大窗体动态排版；任务栏多行换行；弹窗关闭按钮永远可见。
- **资源精简**：无新增依赖，纯 CSS + 原生 JS（不依赖 @property/mask 高级特性，保证 Electron 兼容）。

## 2. 设计 Tokens（暖调纸面 B 系，全界面 0% 纯白）

| Token | 值 | 用途 |
|---|---|---|
| --bg | #EDEBE4 | 窗口背板 |
| --surface | #F7F5EF | 面板/行 |
| --surface-hi | #FFFDF6 | 弹窗/气泡（米白，非纯白） |
| --line | #E0DDD3 | 发丝线 |
| --text | #2A2723 | 主文字 |
| --text-2 | #8A8577 | 次文字（全局仅两级灰） |
| --primary | #5E6AD2 | 主色（唯一强调色：激活态/主按钮/计数徽标） |
| --danger | #E5484D | 危险 |
| --ok | #4CB782 | 已完成 |
| --warn | #C9A227 | 修复中 |

- 圆角：标签/按钮 7-10px；卡片 10-12px；弹窗 14px。
- 阴影：仅浮层与"最上层"元素（激活标签/弹窗/抽起的牌）；列表不投影。
- 图标：24×24 画布、1.8px 圆头描边、单色 currentColor（自动适配暗色主题）。

## 3. 组件规格

### 3.1 连接状态点（三态）
- 已连接：10px 绿点 + 浅绿光环，1.8s 呼吸（opacity 1↔.55）——安心感。
- 连接中：琥珀 #D9A23B，1s 闪烁。
- 断开/异常：红 #E5484D 实心，状态文案同色变红——不可忽略。

### 3.2 图标（用户选定 12 个）
01 图片山日（截图占位/通用）、02 相框对焦（预览）、04 上传、07 放大预览、08 垃圾桶、09 关闭、11 清单、12 新增、16 服务器（主机模式）、17 显示器（客户端模式）、18 用户（署名）、19 保存（备份）。
未选图标（03 相机 / 05 剪贴板 / 06 拖拽手柄 / 10 叠放 / 13 气泡 / 14 便签 / 15 铅笔 / 20 信号）暂不引入；备注按钮沿用现有气泡图形并细化到同一描边规范。

### 3.3 扑克牌堆（条目截图多图）
- 叠放：第 1 张最上层最显眼（左近竖直、-5°），2/3/4 依次向右下垫底（旋转递增、z 递减）；右下角计数徽标"n 张"。
- hover：碰到哪张哪张弹起 -9px 并扶正（弹性 overshoot `cubic-bezier(.3,1.7,.45,1)`，260ms）+ 阴影加深 + z 提到最上；其余张不动。
- press：抽起那张压下（70ms 跟手）。
- 展开：从所点卡片的 rect 放大（260ms `cubic-bezier(.2,.8,.2,1)`）；**背景变黑与放大同步**（260ms 淡至 rgba(28,26,23,.88)），落定后舞台 160ms 淡入（scale .965→1）——无闪黑断层。
- 查看器：**精确停在所点那张**（n/N 提示）；←/→ 260ms 平移；× 或点背景关闭。
- 关闭：舞台快速淡出 + 画面**缩回所点卡片原位**（280ms 反向动画）+ 背景同步淡出——空间闭环。

### 3.4 删除按钮（四态 + 蓄怒 + 保险 + 破坏，全链路）
- 悬停：-1px 上浮 + skewX(-1°) + 红光晕（0 3px 10px rgba(229,72,77,.25) + 3px ring .08）。
- 按下（<700ms）：scale(.97) + skew 交替 + ±0.8px 高频颤抖（160ms 循环）+ 红色内发光（蓄力）。
- **长按 ≥700ms（蓄怒）**：背景 550ms 渐黄 #F3C464 → 红 #E5484D（字转白），颤抖升级至 ±1.3~1.5px 带微旋转（幅度仍克制，只有趋势）。
- **松手位置判定（扳机保险）**：以按下时按钮 rect±3px 判断；鼠标不在按钮上 → 删除终止（静默复位，不弹确认）；在 → 释放抖动（±2.4px 衰减 420ms）+ 红圈脉冲向外扩散。
- 确认气泡：米白 #FFFDF6 圆角 10px 弹性弹出；确定=红底白字，取消=描边灰字；点远处黑幕 = 取消。
- **注意力板**：整体渐隐黑 rgba(28,26,23,.5)（240ms 淡入/淡出）；被删行**矩形柔光环**（0 0 0 4px rgba(255,255,255,.65) + 软投影）捧出——矩形与行形状一致，不用圆形放射。
- **破坏（确认后）**：黑幕渐亮 → 被删行红光一闪（160ms）→ 行高钉死像素后过渡到 0（320ms，border-box）→ **下面一行随布局自然上滑覆盖**（带 -8px 投影），文字被完全压住后才从 DOM 移除。
- **实现红线（防回归）**：①height 必须从具体 px 过渡到 0（auto→0 无过渡，会瞬移）；②不得对下面行叠加 transform（布局回流已上移 h，再 transform 会双重移动冲过头、结束回弹）。

### 3.5 新增按钮（垒上·定稿）
- 悬停：-3px 提起 + 阴影渐深（像拿起积木）。
- 按下：+2px 稳稳落定（90ms）+ "＋"号旋转 90°。
- 松开：轻弹回落（+2px → -1.5px → 0，340ms 弹性，幅度克制）。
- 结果动画：新任务行"生长"进入（max-height 0→60px + opacity + translateY(-4px)，300ms 弹性）。

### 3.6 上传按钮（托举发射·定稿）
- 悬停：-2px 上浮，↑箭头抬 1.5px。
- 按下：+2px 下沉、箭头下压（蓄势压弓）。
- 松开：按钮弹起过冲 -4px；**箭头飞出渐隐**（-9px + opacity 0，300ms）——文件被送上去。
- 到达：目标牌堆**一张新牌从上落入**（-46px scale .85 → 弹性落定，420ms），计数 +1——送到即到货。

### 3.7 备注按钮（便签翘角展开·定稿）
- 悬停：-2px + rotate(-1.3°)（便签一角翘起）。
- 按下：贴平（rotate 0、+1px、scale .97）。
- 松开：弹回过冲 +0.8°。
- 面板：**从按钮处展开**（scale .85→1 + rotate -3°→0，280ms 弹性，transform-origin 左上）；米白 #FFFDF6、圆角 10px、软投影。

### 3.8 任务栏（多行 + 拖拽）
- flex-wrap 多行换行，窗口变窄自动转行，**无横向滚动**。
- 拖拽排序保持抽卡手感；**落点高亮跟随指针**（插入前/后指示，跨行有效），松手才判定位置——实时反馈替代"松手才知道"。

### 3.9 备注多图（note.images）
- 数据：`note.image`(string) → `note.images`(array)，migrateData 自动迁移（同 bug.image→images 模式）。
- 展示：与条目截图同款牌堆（缩小版 44×60），点击从第一张开始进入查看器。
- 上传/删除/预览/动画：全部复用条目截图全套交互；两步式提交扩展为多文件（X-Note-Id / X-Bug-Note-Id 逐张暂存后 addNote 携带 images 数组）。

## 4. 响应式规则

- 小窗体（宽 <900px）：紧凑布局——行内不折行、留白收紧、牌堆缩至 3 张可见。
- 大窗体（≥1200px）：动态排版——任务栏多行、行内四栏定宽对齐（名称弹性/状态/备注/截图）、行高 ≥44px、留白加大、次要信息（备注/截图计数）弱化灰色。
- 弹窗：宽 ≤86vw、高 ≤72vh，关闭按钮与翻页控件永远在可视区；查看器图片 object-fit:cover 阶段为 contain（保比例）。
- 无横向滚动；所有尺寸使用现有 CSS 变量体系，改 Token 即全站换肤。

## 5. 非目标（本期不做）

- 暗色主题（留后期，Tokens 已预留 currentColor 图标与语义变量）。
- 移动端/触屏完整适配（当前局域网桌面场景；触控目标 ≥36×36px 尽力而为）。
- prefers-reduced-motion（后期加开关）。

- `note.image → note.images[]` 迁移 + 迁移备份（沿用 imageMigrationBackedUp 模式，独立标志 noteImagesMigrated）。

- addNote/addBugNote 的 note 对象携带 `images` 数组（服务端 `{...note}` 透传）。
