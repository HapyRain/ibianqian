## 文档信息
- **日期**: 2026-07-07
- **当前系统**: Node.js + ws + Vue 3 + Element Plus + Electron

## 需求 1：服务器地址记忆 + 连接失败提示 → localStorage + onclose 反馈

**方案**: localStorage 持久化 + WebSocket 断连检测

### 地址记忆（同原方案）
- key `buglist_server_host`
- 初始化优先读 localStorage，fallback `location.host`
- `onServerChange` 时同步写入 localStorage
- setup() 顶层立即赋值避免闪烁

### 连接失败提示（新增）
- 监听 ws `onclose` 事件：当保存的地址连接失败时，**不静默重连**
- 状态指示器变红（红色圆点或边框），旁边显示中文提示：
  > 「连接失败，服务器端口可能已变更，请联系服务端确认地址」
- 提示文字替换原有状态文字区域，红色高亮
- 用户看到提示后可手动修改地址输入框重新连接
- `onopen` 时恢复绿色状态指示器 + "已连接"文字

### 防抖处理
- onclose 首次触发立即提示，后续 5 秒内的重复 onclose 忽略（避免闪烁）
- 用户手动修改地址时重置防抖计数器

**文件**: `public/app.js`（~25行新增）、`public/index.html`（~10行新增）、`public/style.css`（~8行新增）

## 需求 3：Bug 图片上传（三种方式 + 无大小限制） → 文件存储 + HTTP 上传

**方案 B**: 图片存 `public/uploads/`，data.json 仅存文件名

### 三种上传方式（共用同一处理函数）

**核心函数**: `handleImageUpload(file: File | Blob)` — 三种方式统一调用此入口

| 方式 | 触发条件 | 交互说明 |
|------|----------|----------|
| **点击上传** | 点击缩略图区域 | 打开 `<input type="file" accept="image/*">` 文件选择器 |
| **拖拽上传** | 拖拽图片到缩略图区域 | 监听 `dragover`/`dragleave`/`drop` 事件，拖入时边框高亮（蓝色虚线→实线） |
| **Ctrl+V 粘贴** | 页面任意位置 Ctrl+V | 监听 `document` 的 `paste` 事件，从 `clipboardData.items` 提取图片 Blob |

### 拖拽视觉反馈
- `dragover` 时：缩略图区域边框由灰色变为蓝色高亮（`border: 2px dashed #409eff` → `2px solid #409eff`），背景加浅蓝遮罩
- `dragleave` / `drop` 后恢复默认样式

### 粘贴关联逻辑
- 粘贴时判断 `editingBugId` 是否存在：
  - 存在 → 图片关联到该 Bug
  - 不存在 → toast 提示「请先双击进入编辑模式再粘贴图片」，不执行上传

### 去掉限制（本地局域网场景）
- **无文件大小限制**（删除 2MB 限制，局域网内存不是瓶颈）
- **无图片压缩**（删除 Canvas 压缩逻辑，保持原图画质）
- 保留 MIME 白名单 + 魔数校验（安全校验不受影响）

### HTTP 端点
- `POST /api/upload` — multipart/form-data 上传，返回文件名
- `DELETE /api/upload/:filename` — 删除图片

**数据模型**: bug 新增 `image: string | null` 字段

**文件**: `server.js`（+55行）、`public/index.html`（+40行）、`public/app.js`（+80行）、`public/style.css`（+50行）

## 关键风险

| 风险 | 缓解 |
|------|------|
| 单实例锁开发环境不生效 | 打包后验证 |
| el-select 自定义 trigger 下拉箭头消失 | 手动补箭头 icon |
| 新增 Bug 排序"跳动"（待修复排中间） | 添加黄色高亮闪烁动画引导 |
| 图片文件残留 | 删除 Bug 时同步清理，服务端主动清理旧图 |
| 大图片内存占用（无大小限制） | 缩略图用 CSS object-fit 缩放，原图按需加载；局域网场景实际图片通常 < 50MB |
| 拖拽区域视觉反馈误触（快速划过） | 设置 100ms debounce 后再显示高亮，避免闪烁 |
| 剪贴板粘贴非图片内容误触发 | 读取 clipboardData 前检查 `item.type.startsWith('image/')`，非图片类型忽略 |
| ws onclose 重复触发导致提示闪烁 | 5 秒防抖窗口，用户手动重连时重置 |

## 验收清单

- [ ] 地址记忆: 刷新/重启后恢复上次输入的服务器地址
- [ ] 连接失败提示: 保存的地址连不上时，状态指示器变红 + 显示中文提示，不静默重连
- [ ] 连接恢复: 用户手动修改地址重连成功后，指示器恢复绿色 + "已连接"
- [ ] 防抖: 5 秒内重复 onclose 不产生新提示，手动重连时重置
- [ ] 单实例: 双击 exe 两次只有 1 个窗口 + 1 个托盘图标
- [ ] 图片点击上传: 点击缩略图区域打开文件选择器，上传后缩略图显示、广播同步、点击弹大图
- [ ] 图片拖拽上传: 拖拽图片到缩略图区域，拖入时边框高亮，松手后上传
- [ ] 图片 Ctrl+V 粘贴: 编辑模式下 Ctrl+V 粘贴剪贴板图片自动关联到当前 Bug；非编辑模式下提示先双击编辑
- [ ] 图片无大小限制: 大图（>50MB）可正常上传，不做压缩
- [ ] 图片删除清理: 删除 Bug 时同步删除服务端图片文件
- [ ] 颜色: 三种状态显示为彩色标签，点击可切换
- [ ] 排序: 修复中 > 待修复 > 已完成
- [ ] 筛选: 按钮组切换过滤，显示数量，过渡动效
